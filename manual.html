適用 Windows 的 Chrome／Edge。網頁放在 GitHub Pages；音訊取得、分離與評分在你的電腦進行。先完成一次安裝，之後從本機歌單載入就能再唱。

每次使用

已安裝？照這 6 步開始

  1. 執行工具資料夾的 start-local.ps1，用 Chrome 或 Edge 開啟主畫面。
  2. 按檢查本機工具，確認顯示已就緒。
  3. 按主畫面上方的歌曲庫，在本機歌單 · 點一首就載入裡點選歌曲；新歌先在歌曲網址貼上連結，再到聲曲分離與音高旋律擷取按準備歌曲基準。
  4. 戴耳機，開啟麥克風，確認說話時音量條有反應。
  5. 到評分設定，啟動，與成績選評分難度與評分範圍，再按從頭開始唱；成功啟動後，畫面自動捲到播放器，影片從 0 秒重新開始。
  6. 唱完按結束並結算。同一首再唱，直接按從頭開始唱。

主畫面頂端的配色可選「冷色調」或「暖色調」，冷色調使用深藍灰底與冰藍／青色重點，暖色調使用深咖啡底與琥珀色重點。預設為冷色調；此瀏覽器會記住你的選擇，切換時立即生效。下方「從頭開始唱／結束並結算」按鈕寬度為 2:1。主畫面上方有固定的區段導覽。按播放器、歌曲庫、收音、評分／結算可直接跳到該區；按操作手冊 ↗會開啟新分頁。切到手冊會停止收音，建議開始演唱前先閱讀。

「評分範圍」預設為只比已演唱範圍，後面尚未唱到的部分不扣分。要挑戰完整歌曲時，再自行切換為「整首歌曲」。

STEP 01 · 只需初次安裝

安裝並啟動本機工具

  1. 安裝 Node.js 22 以上、Python 3.12、FFmpeg／ffprobe，並讓指令能從 PATH 執行。
  2. 從專案 GitHub下載程式碼，解壓縮到固定資料夾。之後在該資料夾開啟 PowerShell。
  3. 執行安裝指令。安裝會下載套件，需要網路與磁碟空間：
    powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-local.ps1
  4. 安裝完成後啟動：
    powershell -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1
  5. 網站開啟後按檢查本機工具。若瀏覽器詢問本機網路存取，允許本站。

已有舊版工具，要使用主唱／和音分離：先執行 stop-local.ps1，更新工具程式碼後重跑安裝指令，再啟動。歌曲庫與模型不會因重跑安裝而移除。

重開機後需重新啟動工具；重灌 Windows 或換電腦則需重新安裝。此流程目前以 Windows 桌機為主，尚未完成 iPhone 的本機處理流程。

STEP 02 · 每台電腦各自設定

指定歌曲庫資料夾

  1. 在你的本機歌曲庫按選擇資料夾。
  2. 在 Windows 視窗選一個你要保存歌曲的資料夾，確認選取。也可輸入完整路徑，再按使用此位置。
  3. 確認網頁顯示設定成功；以後會記住這台電腦的選擇。

第一次一定要指定位置，別人的電腦不會沿用你的路徑。切換位置只改成讀取另一個歌曲庫，不會搬動或刪掉原本歌曲。若歌曲仍載入，先按歌曲區的取消／卸載再換資料夾。

選擇視窗沒出現時，檢查是否被其他視窗遮住；可按取消資料夾選擇，改用完整路徑。

STEP 03 · 新歌才需要等待

建立歌曲基準

  1. 貼上 YouTube 影片網址。選有清楚原唱的版本；純伴奏通常無法建立旋律基準。
  2. 選分析範圍：完整歌曲最長 15 分鐘，也可先試前 15／30／60 秒。前奏很長時，太短的片段可能沒有足夠歌聲。
  3. 選聲曲分離模型：Demucs 是原本的預設模型；要比較效果可選 BS-RoFormer／Viperx 1297，或 Mel-Band RoFormer／Kim 人聲。
  4. 選聲曲分離模式；預設維持人聲／伴奏分離。進階主唱模式見下一節。
  5. 保留保留分離音軌，供本機試聽的勾選；不需要試聽才取消。
  6. 按準備歌曲基準，等待狀態顯示已就緒。

進度依序是取得音訊、聲曲分離、選用的主唱／和音分離、建立基準、可開始唱。第一次需下載模型；分離時間與歌曲長度、CPU／GPU 有關。百分比只在模型提供實際推論進度時顯示。分離 100% 不等於整個工作完成：之後還要完成音軌、建立基準並保存。請等「已就緒」及試聽按鈕亮起；期間不用再按準備或重做。

支援的 NVIDIA CUDA 環境會優先用 GPU；GPU 記憶體不足等錯誤會改用 CPU 重試，進度會重新開始。結果自動保存，同一影片、分析範圍、分離模型、模式與音高方式可直接重用。

STEP 04 · 先用耳朵確認

模型比較、主唱／和音分離與試聽

三種人聲分離模型

模型用途
Demucs／htdemucs（預設）原本的分離模型，舊歌曲可繼續載入。
BS-RoFormer／Viperx 1297另一種人聲／伴奏分離模型，供比較試聽。
Mel-Band RoFormer／Kim 人聲Kimberley Jensen 的人聲模型，首次下載約 913 MB；與後續主唱／和音分離使用的模型不同。效果依歌曲而異，不能保證完全去除樂器。
  1. 先載入要比較的歌曲，保持相同分析範圍。
  2. 將聲曲分離模型改成 Mel-Band RoFormer／Kim 人聲，保持保留分離音軌勾選，再按準備歌曲基準。只改選項不會切換正在試聽的版本。
  3. 等到已就緒，確認試聽來源標示 Mel-Band RoFormer，再按試聽人聲／試聽伴奏。
  4. 在本機歌單點選 Demucs、BS 或 Mel 的對應版本，即可切換比較。新模型的結果另存，不覆蓋舊版本；相同影片與分析範圍的遮罩共用。

三種模型都可搭配下方兩種處理流程：3 × 2＝6 種組合可並存；再選不同人聲模式或 YIN／RMVPE 也會分開保存。新模型需要新版本機工具：更新程式碼後停止並重啟工具，網頁按 Ctrl＋F5；已有 RoFormer 套件時不需重裝。

歌曲基準的兩種處理流程

選項做法
單次分離（預設）沿用原有流程，直接以模型分離的人聲建立基準。
伴奏二次分離＋反向相減先分離原曲，再用同一個所選模型分離第一輪伴奏；以原始混音 M 減去第二輪伴奏 I₂，得到新的評分人聲。這是實驗選項，效果不保證更好。
  1. 在聲曲分離與音高旋律擷取選好分離模型，將歌曲基準處理流程改成伴奏二次分離＋反向相減。
  2. 保持保留分離音軌勾選，按準備歌曲基準。若提示本機工具需要更新，先更新工具包並重新啟動；原有模型可重用，不需因新流程再下載一套模型。
  3. 等待「聲曲分離 → 伴奏二次分離 → 反向相減 → 建立基準 → 可開始唱」。若有選主唱／和音，會在反向相減後再分離主唱。每個分離階段的百分比獨立計算，100% 不等於全部完成。
  4. 看到已就緒後，展開分離結果試聽（選用），確認上方「目前已載入」標示正確流程，再按試聽人聲或伴奏。伴奏為第二輪結果，人聲為 M − I₂。
  5. 從歌曲庫點選同一首的單次分離版本，即可切回比較；只改下拉選項不會立即換音軌，需再按準備。

兩種流程各自保存，舊歌曲視為單次分離，不會自動重做或被覆蓋。兩種流程、不同分離模型和 YIN／RMVPE 都共用同一影片、同一分析範圍的遮罩。重新分離只替換目前所選版本，失敗的新結果不保留，舊版本仍保留。

新方法會多跑一次完整分離，耗時與暫存空間較多；它可能找回伴奏裡的人聲，也可能保留或增加樂器殘留，請用試聽比較。相減過程使用對齊的未壓縮浮點 WAV 並保留振幅，不拿試聽 MP3 相減；完成後仍只保留基準及勾選的試聽音檔。

比較 Demucs 與 BS-RoFormer：先從歌曲庫載入舊歌，將「聲曲分離模型」改成 BS-RoFormer，保持「保留分離音軌」勾選，再按「準備歌曲基準」。第一次需下載約 639 MB 的另一個模型；完成後按「試聽人聲／伴奏」。歌單會另增一筆 BS-RoFormer 版本，點 Demucs 那筆即可切回比較，兩種模型都能搭配主唱／和音模式。試聽訊息也會標示目前模型。

既有歌曲不會搬移、改寫或自動重做，沒有模型欄位的舊資料會視為 Demucs。只切換選項不會立即改動音軌，須按準備或重做。試聽區會以亮色顯示「目前已載入」的歌曲、模型、流程與模式；改選不同分離模型／模式／流程後，舊試聽會停止並停用，等新版本就緒或從歌單載入對應版本才可播放。YIN／RMVPE 只換音高辨識，相同分離版本的試聽音軌仍相同。模型效果依歌曲而異，不代表換模型一定提高分數。

模式音高評分依據可試聽音軌
人聲／伴奏（預設）全部人聲，可能包含和音人聲、伴奏
主唱／和音（選用）模型估計的主唱人聲、伴奏、主唱、和音
  1. 要減少和音干擾，準備歌曲前把聲曲分離模式改成主唱／和音分離。
  2. 保持保留音軌勾選，按準備歌曲基準。第一次會額外下載約 913 MB 模型；之後保留在本機重用。
  3. 確認就緒訊息顯示主唱／和音模式，再點亮色大字標題分離結果試聽（選用）展開，分別按試聽主唱與試聽和音，用音訊播放器拖曳到有和聲的段落比較。
  4. 若主唱被切掉太多，改回預設模式，按準備歌曲基準載入或建立該模式的基準。

這是模型估計，並非可靠的歌手身分辨識。重疊齊唱、二重唱、重唱疊軌仍可能分錯；沒有和音的歌，和音軌可能很安靜。請先試聽再決定使用哪種基準。

兩種模式分開保存，不會互相覆蓋。試聽會暫停 YouTube，不參與評分；開始播放 YouTube 會停止試聽。舊歌沒有音軌時，按補建試聽音軌，完成後即可聽。

選用 · 原有 YIN 仍為預設

用 RMVPE 比較歌聲音高基準

RMVPE 是歌聲音高模型，針對伴奏干擾設計；此選項只影響原唱評分基準，不會清除試聽音軌裡的樂器，也不會改變麥克風即時偵測方式。效果需以歌曲比較，不能保證完全不誤判。

  1. 從歌單載入原本的歌曲，例如《吻別》，保持原本的完整歌曲／分析範圍與分離模型、模式。
  2. 把基準音高擷取從 YIN 改為RMVPE。
  3. 按準備歌曲基準。如果相同分離模型與模式已有保存音軌，就直接重用，只重建音高與節拍基準；沒有音軌才重新取得音訊及分離。比較音高時，不必按「重新分離並覆蓋」。
  4. 首次下載約 181 MB 權重，存於工具資料夾 .runtime/models/rmvpe/rmvpe.pt，所有歌曲共用。模型檔大小不等於執行時記憶體用量；推論採分段處理，優先 GPU，GPU 記憶體不足可改用 CPU。
  5. 等待已就緒，確認訊息及歌單標示 RMVPE 音高。YIN 與 RMVPE 各自保留基準；點歌單對應版本即可比較，舊歌預設視為 YIN。
  6. 手工遮罩是最後評分時才套用，同一影片、同一分析範圍跨分離模型、人聲模式與音高方式共用，換模型不必重標。

原本歌曲與遮罩不會被新版本覆蓋。只改下拉選單尚未套用；已在唱的一輪不能切換。更新頁面後若提示工具太舊，更新程式碼、停止並重啟本機工具，再重新整理頁面；已安裝現有音訊套件的電腦不需額外安裝 RMVPE 套件。

選用 · 預設沒有遮罩

樂器被認成歌聲？設定不計分區間

  1. 先從本機歌單載入已分離好的歌曲，不需要重新分離。
  2. 在 YouTube 播放器下方展開不計分區間遮罩。建議在開啟麥克風前設定；已有一輪演唱時，先結束並結算才能修改。
  3. 播放到需要排除的段落，按現在位置設為起點，到段落結尾按現在位置設為終點。也可手動輸入秒數或分:秒，例如 32.5 或 1:02.5。
  4. 按新增並保存遮罩，確認顯示「已保存」。可新增多段，重疊或相接的區間會合併。保存失敗時不套用新遮罩，請看錯誤訊息後重試。
  5. 開始演唱後，遮罩區間的右側原唱音符顯示休息，藍色基準線中斷；音準、進拍、完整度都不計入。影片仍正常播放，也不會靜音。
  6. 要調整區間，刪掉該段再新增；按清除全部遮罩即可恢復原本基準的評分。

遮罩自動存到你指定的本機歌曲庫，綁定原始影片與分析範圍。同一影片、同一分析範圍的 Demucs／BS-RoFormer／Mel-Band RoFormer、人聲／主唱模式、YIN／RMVPE 共用一份遮罩；在任一版本修改，其他版本下次載入也會套用，換模型或重做不必重標。只在評分與基準顯示時套用，不裁切音檔。既有舊版遮罩會優先採用最近保存且非空的一份；後續修改即寫入共用檔。

起點包含、終點不包含；實際排除以基準時間格為單位（目前約 0.1 秒），與區間重疊的時間格整格排除。每輪開始後固定遮罩，暫停仍不能修改，結算後才可再改。整首／已演唱兩種評分範圍都適用；如果本輪只經過休息或遮罩區間，不會產生分數。

STEP 05 · 每輪開始前設定

開啟麥克風，從頭開始唱

  1. 戴上耳機，選好收音麥克風，按開啟麥克風並允許權限。說話時確認音量條與音高有反應。
  2. 在評分難度選標準、嚴格或寬鬆。預設標準沿用原本規則；嚴格適合精準練習，寬鬆適合輕鬆練唱。每輪開始後固定，分數上方會標示本輪難度。
  3. 在音域比對保留允許高／低八度，男聲唱女聲旋律時可低八度；選嚴格原調才要求與原唱同音高。
  4. 選評分範圍。預設只比已演唱範圍，只評開始至停止的播放區間，區間內的漏唱、跳過仍會扣分。改選整首歌曲才會把提前結束的剩餘段落算漏唱。
  5. 按從頭開始唱。系統開啟麥克風、等待播放器回到 0 秒，再清除上一輪資料開始評分。原本正在播放也會重新開始。麥克風就緒且播放器確認回到 0 秒後，畫面自動捲到播放器，位置會避開上方固定導覽列，不必自己往上找影片。
  6. 保持此網頁在前景。亮色線是你的聲音（冷色調為青色、暖色調為琥珀色）、藍線是原唱基準；允許八度差時兩線不一定重疊。

也可在歌曲基準與麥克風都就緒後直接按 YouTube 播放，從當時的播放位置開始評分。需要每次從頭一致練習，請用從頭開始唱。

三種難度怎麼比？

難度音準滿分誤差進拍滿分誤差
標準（原有規則／預設）±25 音分±80 毫秒
嚴格±15 音分±40 毫秒
寬鬆±50 音分±120 毫秒

100 音分＝1 個半音。超過滿分範圍後逐步扣分；嚴格／標準／寬鬆的單格音準分別在 100／200／300 音分歸零，單個起音的進拍分別在 200／350／500 毫秒歸零。漏唱仍扣分，完整度算法與三項權重相同。

難度、允許高低八度、整首／已演唱範圍是三個獨立設定。改難度不用重新分離歌曲；結算後選下一輪難度，再按「從頭開始唱」。歌曲初次就緒時也可直接按 YouTube 播放，會使用開始當時所選難度；結算後再唱請按「從頭開始唱」。

這些是本工具自訂的練習門檻，尚未經真人評分校準。「標準」不代表業界統一標準；分離品質與收音延遲也會影響分數。歷史紀錄仍只保存歌名與分數，不另保存難度，跨難度的歷史分數不宜直接比較。

評分是音準 60%、進拍 25%、完整度 15%。不辨識歌詞；唱錯字但音高相同，無法據此判定。設定在本輪開始後固定，下一輪可再改。

STEP 06 · 唱一段也能結算

停止、結算與再唱一次

操作會發生什麼事
暫停 YouTube暫停評分；緩衝時也不計分。
停止收音停止並保存本輪錄音，釋放麥克風，播放器暫停並回到 0 秒；保留本輪評分資料，可再按結束並結算。
結束並結算結算本輪、保存分數，並停止與保存本輪錄音（若有啟用）；歌曲基準與試聽仍保留，可直接再唱。
從頭開始唱麥克風與播放器就緒後，清除上一輪尚未結算的演唱資料，自動捲到播放器，從 0 秒重新計分。
YouTube 播完有進行中的演唱時會自動結算。

只分析前 30 秒時，播放超過 30 秒就不再累計該基準之外的聲音，但不會強制結算或停止影片。中途結束仍按結束並結算。

只試麥克風、尚未開始歌曲評分時，不會產生一輪分數。切到其他分頁或裝置中斷會停止收音，回來需重新開啟；已有演唱資料仍可結算。

演唱錄音與分數紀錄

  1. 在評分設定，啟動，與成績找到演唱錄音儲存。錄音內容有「歌唱者」（預設）與「歌唱者＋配樂／和音」兩種，也可選「不保存錄音」關閉錄製。此瀏覽器會記住選擇；選不保存後只收音評分，不啟動錄音器。
  2. 在錄音音量平衡，預設不勾選「手動設定比例＋自動微調」，由系統自動平衡歌唱者與配樂／和音，各路最多修正 ±6 dB。勾選後可先調歌唱者、配樂／和音音量（0–100%），系統以這個設定為基礎，只微調 ±3 dB；0% 保持靜音。兩個百分比是各自音量，不必加總為 100%。設定會記住，每輪開始後固定；歌唱者模式不使用配樂／和音滑桿；配樂與和音合為一路調整，保留兩者相對比例。
  3. 混音需已保存分離音軌；沒有時先補建。系統依已載入版本判斷：一般兩軌版本加入伴奏；主唱／和音四軌版本加入伴奏＋和音。兩條音軌同步跟隨播放、暫停與跳轉；缺少應有音軌時會提示補建，不會偷偷省略和音。不加入原唱主唱或全部人聲，也不擷取 YouTube 網頁聲音。錄音清單會標示有無獨立和音。請戴耳機，避免喇叭聲再漏進麥克風。
  4. 按從頭開始唱，完成麥克風與播放器同步後，影片播放時開始錄音。暫停或緩衝時錄音也暫停；跳轉會跟隨新位置，儲存的是實際演唱順序。歌唱者模式完全不混入伴奏或和音。
  5. 按停止收音、結束並結算或等影片播完，會自動停止並保存錄音。重按「從頭開始唱」會先保存上一段，再另開一段，不覆蓋；只按 YouTube 播放或單獨測試麥克風不會另開錄音。
  6. 展開演唱錄音 · 試聽／下載，可試聽、下載或刪除個別錄音。桌機 Chrome／Edge 通常保存 WebM／Opus 音訊。錄音存於目前瀏覽器本機資料，不上傳；清除網站資料會刪除錄音，請下載重要檔案。
  7. 展開分數紀錄 · 勾選清除，勾選需要刪除的紀錄，按清除勾選紀錄；可全選，也可直接按全部清除。這些操作只刪分數，錄音與歌曲庫不受影響。

伴奏只涵蓋準備歌曲時的分析範圍；超過音軌長度後，錄音仍會繼續保存歌聲。錄音的自動音量採平滑調整，低於門檻或未偵測到穩定歌聲時不自動增強麥克風；輸出有壓縮及峰值保護。這是音量平衡，不是自動 EQ；無法修復麥克風本身已經破音的訊號。混音不加入音高評分的麥克風訊號，遮罩也只影響評分，不會把錄音消音。藍牙與裝置延遲仍可能造成聽感上的不同步。

切到背景或換裝置會停止收音並嘗試保存。錄音期間約每秒把音訊片段存入本機資料庫；意外關閉時只能保留已寫入的片段，清單會標示未正常結束。儲存空間不足時會顯示「下載未保存錄音」，請在關閉頁面前下載備份。

STEP 07 · 下次不用重新分離

載入、重做與刪除

  1. 按主畫面上方的歌曲庫，會自動捲到並展開歌單；也可直接點本機歌單 · 點一首就載入的大字亮色標題展開或收合。下方顯示已保存的基準數量，必要時按重新整理歌曲庫。
  2. 點歌曲名稱直接載入；會卸載前一首的記憶體工作，但不刪除前一首保存的資料。
  3. 要重做：載入該歌，選好分離模型、模式與是否保留音軌，再按重新分離並覆蓋。會跳過快取，成功後才替換同一影片、範圍、模型、流程、音高方式、模式的結果。
  4. 要移除：按該筆的刪除，會刪掉這筆基準與試聽音檔。其他模型、範圍或模式的版本不受影響。

如果新分離失敗，新產物會清除；已保存的舊結果在新結果成功前保留。不同模型、分析範圍與分離模式是不同筆。變更模式後按準備或重做，才會真正切換基準。

進行中的演唱請先結束並結算，再重做、補建或換歌。歌曲區取消／卸載釋放目前工作，不等於刪除歌曲庫。

STEP 08 · 選用

五音延遲測試

  1. 開啟麥克風，展開Do Re Mi Fa Sol 五音延遲測試。
  2. 選跟唱，或把耳機／喇叭靠近麥克風的聲音回收模式；再選適合的高低音域。
  3. 按播放五音並測試，跟唱或讓麥克風收回測試音。
  4. 穩定辨識至少 4 個音才提供建議；按套用建議補償才會改動數值。也可手動調整。

跟唱結果包含人的反應時間；聲音回收測的是網頁音訊往返時間，可能與 YouTube 不同。補償只調整評分比對位置，不會消除藍牙耳機本身延遲。換裝置後重新測試，先用有線設備較容易比對。

遇到問題，依序檢查

按從頭開始唱沒反應／沒有收到聲音

先看麥克風狀態。在 Chrome／Edge 網址旁的網站權限允許麥克風，再確認 Windows 麥克風權限、輸入裝置與音量。回到頁面按開啟麥克風；看到音量反應後再唱。若等待 YouTube 同步，確認播放器已載入且沒有錯誤提示。

做了分離卻沒有試聽音軌

已保存的舊結果可能只含數值基準。展開分離結果試聽，按補建試聽音軌，等到已就緒；或保持保留音軌勾選，重新分離並覆蓋。主唱與和音兩個按鈕只出現在已載入主唱模式的歌曲。

已選主唱模式，試聽主唱／和音仍不能按
  1. 先從歌單載入要處理的歌曲，再選主唱／和音分離，避免載入一般人聲版本時切回原模式。
  2. 保持保留分離音軌勾選，按準備歌曲基準。只改下拉選項還不會處理音軌；畫面會提示「尚未套用」。
  3. 等待就緒訊息顯示主唱／和音模式，再按對應試聽。如果只有「一般人聲模式」，代表尚未載入主唱版本。
  4. 若畫面與行為不一致，按 Ctrl＋F5 更新主畫面後重試。舊版頁面可能載入了快取程式而未送出主唱選項；已保存的一般版本可保留，不必先刪除。
按從頭開始唱後，沒有自動捲到播放器

自動捲動發生在麥克風與播放器同步成功後。若仍等待麥克風授權、授權遭拒或 YouTube 同步失敗，先查看收音區與評分區的提示。允許麥克風並確認播放器可播放後，再按一次「從頭開始唱」。

只唱一小段，分數卻很低

目前預設「只比已演唱範圍」。如果曾切換到「整首歌曲」，開始前改回來；整首模式會把沒唱完的部分算漏唱，本輪開始後不能事後變更範圍。也要試聽基準、確認麥克風與延遲，不能只靠總分判定原因。

本機工具無法連線／主唱分離缺少套件

確認已執行 start-local.ps1，允許本站本機網路權限。升級進階分離需更新程式、停止工具、重跑 setup-local.ps1，再啟動；之後 Ctrl+F5 重新整理網頁。只有更新雲端網頁，不會自動安裝每台電腦的 Python 套件。

BS 分離到 100% 後顯示 WAV 編碼不支援

舊版在處理 MP3 輸入時可能於匯出音軌失敗。更新本機工具程式碼後，停止並重新啟動工具，再重新準備歌曲；模型不必重新下載。失敗的新結果未保存，舊歌曲版本仍保留。修正版會先解碼輸入，避免混用壓縮編碼與 WAV。

分離很久、百分比不動

首次可能正在下載模型；CPU 處理整首歌也比較久。查看目前階段及 GPU／CPU 標示。無實際百分比的階段不會假造進度。可先用有歌聲的前 30／60 秒測試；需要中止時按取消／卸載。

和音仍被當成主唱／主唱被切掉

主唱／和音模型可能判錯。先切換試聽主唱、人聲，確認哪個較符合歌曲；可回到預設人聲／伴奏模式建立或載入基準。此工具仍是練習用，無法保證每首歌都準確分離。

資料留在哪裡？

  • 你指定的歌曲庫：影片識別資料、歌名、分析範圍、分離模型與模式、數值基準、不計分區間遮罩與選用試聽音檔。可由歌單載入對應 YouTube 影片。
  • 工具資料夾：套件、模型與處理期間的暫存。模型與歌曲庫分開：Demucs 在 .runtime/models 下，BS-RoFormer 在 .runtime/models/bs-roformer，Mel-Band RoFormer 人聲模型在 .runtime/models/mel-roformer，主唱／和音模型在 .runtime/models/lead，RMVPE 音高模型在 .runtime/models/rmvpe。模型由所有歌曲共用，更換歌曲庫不需重新下載。原始混音與大型分離 WAV 在網頁工作完成後清理。
  • 這個瀏覽器：最近的歌名與分數紀錄，以及啟用儲存的演唱錄音。錄音存在 IndexedDB，不上傳，也不寫入歌曲庫資料夾；Chrome 與 Edge 各自保存，重要錄音請下載備份。

GitHub Pages 提供頁面，YouTube 播放、音訊取得及初次模型下載仍需網路。音訊處理在本機，沒有送到雲端分離。
